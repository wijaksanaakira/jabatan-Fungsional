# Sistem Informasi Jabatan Fungsional dan Monitoring Dokumen

Aplikasi berbasis Laravel untuk mengelola Jabatan Fungsional, Dokumen Persyaratan, Monitoring kelengkapan dokumen, dan Autentikasi menggunakan Email/Password dan QR Code.

## Teknologi
- Laravel 11
- Tailwind CSS 3
- Alpine.js
- MySQL/MariaDB
